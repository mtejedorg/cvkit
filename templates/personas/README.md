# Generic reviewer personas

Three readers every candidate meets, written as fictional people so they can be published. The skills read them on every persona panel (see `.claude/skills/cv-builder/06-persona-review.md`).

Your own readers, the people who would actually hire you for the roles you target, belong in your private workspace at `<workspace>/_private/personas/`, one file each in the same format. Ask any of the skills to "create a persona for <role or company type>" and it drafts one from your positioning profiles and the postings you have applied to. A private file with the same `slug` as one here replaces it.

| File | Who | Joins |
|---|---|---|
| `recruiter-screener.md` | An agency or in-house recruiter doing the first pass | Every CV, every public page |
| `ats-parser.md` | The applicant tracking system, as a reader with no judgement | Every CV |
| `hiring-manager-generic.md` | A hiring manager with no domain stated, reading the shortlist | CVs when no private persona matches the family, all public pages |
