# Orbit Courier

A top-down delivery game for the browser. You pilot a courier drone through three districts, dodge traffic and deliver parcels before the timer runs out. Built in Godot 4.3 by one person with AI coding agents (Claude Code).

## Features
- Three districts, 12 delivery routes, a day/night cycle
- Parcels have weight; heavy loads change the drone's handling
- Local leaderboard saved with the SaveManager autoload
- 40 automated tests run headless (godot --headless -s tests/run.gd)

## Status
Playable prototype. No audio yet.
